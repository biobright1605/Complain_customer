# Agent 4 — QA / Software Tester : แผนการทดสอบ

## 1. การทดสอบอัตโนมัติ
| ชุด | คำสั่ง | ครอบคลุม | ผลล่าสุด (3 พ.ย. 2026) |
|---|---|---|---|
| Unit test | `npm test` | กฎ workflow, สิทธิ์, กำหนดตอบ, ผู้รับอีเมล, filter, validate ฟอร์ม | ✅ ผ่าน 25/25 |
| E2E smoke test | `node tests/e2e/smoke-test.mjs` | ไล่ flow จริงผ่าน API ครบทุกบทบาท + export + CSRF + สิทธิ์ผู้ใช้ | ✅ ผ่าน 17/17 (Docker + MariaDB 11.4) |

> smoke test ต้องรันกับระบบโหมดทดลอง (`SEED_DEMO=true`) และจะสร้างข้อมูลจริง — **ห้ามรันกับ production**

## 2. Checklist ทดสอบด้วยมือ (UAT) — ทำบน browser จริง
ยังไม่ได้ทดสอบหน้าเว็บบน browser ในรอบพัฒนา (ตรวจเฉพาะ API + syntax) — ให้ผู้ทดสอบทำตามรายการนี้

### Login / บัญชี
- [ ] login ถูก → เข้าหน้าภาพรวม ; ผิด → กล่องแดง "ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง"
- [ ] กด Enter ในช่องรหัสผ่าน = login
- [ ] บัญชีที่ถูกปิด login ไม่ได้
- [ ] ผู้ใช้ใหม่ / รีเซ็ตรหัส → ถูกบังคับเปลี่ยนรหัสก่อนใช้งาน
- [ ] ออกจากระบบแล้วกด Back ของ browser ไม่เห็นข้อมูล

### ฝ่ายขาย (sales)
- [ ] แจ้งเรื่องใหม่ ไม่กรอกช่องบังคับ → toast แดงบอกชื่อช่อง
- [ ] อีเมล CC ผิดรูปแบบ → toast แดง
- [ ] แนบรูป + PDF หลายไฟล์ (ชื่อไฟล์ภาษาไทย) → แสดงในหน้ารายละเอียดถูกต้อง
- [ ] เลขที่รูปแบบ `SC-YYMMDD-NN` (YY = พ.ศ.)
- [ ] เห็นเฉพาะเรื่องของตัวเอง ; ไม่เห็นผล QA จนกว่าจะปิดเรื่อง
- [ ] ยกเลิกเรื่องต้องพิมพ์เหตุผลก่อน

### QA
- [ ] รับเรื่อง → สถานะ "รับเรื่องแล้ว" + อีเมลถึงฝ่ายขาย
- [ ] บันทึกร่าง → สถานะ "กำลังตรวจสอบ"
- [ ] ส่งทบทวนโดยขาดข้อมูล/ไม่มีหลักฐาน → toast บอกรายการที่ขาด
- [ ] แนบ/ลบหลักฐานได้เฉพาะก่อนส่งทบทวน
- [ ] เข้าหน้าตั้งค่า เพิ่มผู้ใช้ / เปลี่ยนสิทธิ์ / ปิดบัญชีได้ แต่แก้บัญชีตัวเองไม่ได้

### ผู้จัดการ / QMR
- [ ] ผู้จัดการเห็นปุ่มทบทวนเฉพาะเรื่องที่ตรงตำแหน่ง
- [ ] ส่งกลับ / ไม่อนุมัติ ต้องระบุเหตุผล → เรื่องกลับไป "กำลังตรวจสอบ"
- [ ] ชื่อผู้ทบทวน/ผู้อนุมัติมาจากบัญชีที่ login (ไม่มีช่องให้พิมพ์)
- [ ] QMR เข้าหน้าตั้งค่า: แก้อีเมลได้ แต่ผู้ใช้ดูอย่างเดียว

### Dashboard / รายการ
- [ ] การ์ดสถิติ 6 ใบ กดแล้วไปหน้ารายการพร้อม filter
- [ ] กราฟ: แท่ง/เส้น, รายวัน/เดือน/ปี, ภาพรวม/เลือกปี/กำหนดเอง
- [ ] วันที่ผิดรูปแบบ → ขอบแดง + ข้อความ ; Start > End → error ; รายวัน > 366 วัน → error
- [ ] เรื่องเกินกำหนดแสดงสีแดงตัวหนา
- [ ] ส่งออก Excel/CSV เปิดใน Excel ภาษาไทยไม่เพี้ยน, ได้เฉพาะแถวตาม filter

### Responsive
- [ ] จอ < 760px: header บน + bottom nav, รายการเป็นการ์ด
- [ ] ทดสอบบน Chrome, Edge และมือถือ (Android / iOS)

### อีเมล (หลังตั้ง SMTP จริง)
- [ ] ทุก event ส่งถึงผู้รับถูกต้องตามตารางใน handoff + CC รวม + CC รายเรื่อง
- [ ] ลิงก์ในอีเมลเปิดถึงหน้ารายละเอียดเรื่อง

## 3. ข้อสังเกตจากการทดสอบ
- การแนบ/ลบหลักฐานของ QA จะบันทึกร่างให้อัตโนมัติก่อน (กันข้อความที่พิมพ์ค้างหาย) จึงมีบรรทัด "บันทึกผลการตรวจสอบ" เพิ่มใน timeline
- โหมดไม่ตั้ง SMTP: อีเมลจะพิมพ์ลง log ของ container (`docker compose logs app`) แทนการส่งจริง
